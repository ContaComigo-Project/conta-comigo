# Regras de Negócio (RN)

> **A PREENCHER PELO TIME** — nenhuma RN definida até o fechamento do SDD inicial.

## Como escrever uma RN

Uma RN é uma invariante do domínio: continua verdadeira mesmo trocando a
interface, o banco e a linguagem. Ela é a fonte dos casos de borda dos testes.

Formato: `Dado <contexto de domínio>, quando <evento>, então <consequência obrigatória>.`
