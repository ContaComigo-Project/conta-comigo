# Requisitos Funcionais (RF)

> **A PREENCHER PELO TIME** — nenhum RF definido até o fechamento do SDD inicial.

## Como escrever um RF

Formato: `Como <persona>, o sistema deve <capacidade observável> para <resultado de negócio>.`

Um RF é válido quando: descreve comportamento observável, não descreve solução
técnica, e é verificável por um cenário funcional/BDD.
