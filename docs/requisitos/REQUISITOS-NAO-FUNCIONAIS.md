# Requisitos Não Funcionais (RNF)

> **A PREENCHER PELO TIME** — nenhum RNF definido até o fechamento do SDD inicial.

## Como escrever um RNF

Um RNF sem número não é um RNF, é uma opinião. Todo RNF precisa de **métrica**,
**alvo** e **como medir**.

Ruim: "o sistema deve ser rápido".
Bom: "p95 de resposta da API abaixo de 300 ms sob 50 req/s, medido no teste de carga do harness".

## Categorias esperadas

Desempenho · Disponibilidade · Segurança · Privacidade e proteção de dados ·
Observabilidade · Manutenibilidade · Portabilidade · Acessibilidade ·
Custo operacional · Conformidade regulatória.
